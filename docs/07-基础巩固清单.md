## 怎么排（不加时长）

1. **每天八股改成两段**：新题 1 道（8 分钟）+ 旧题抽查 1 道（2 分钟）。旧题从上面 🟡 里随机挑。
2. **项目日顺手串**：写哪块就复习哪块。比如写 W3D1 流式解析，顺手把「事件循环 + 微任务」讲一遍——`onDelta` 回调就是微任务里跑的，一个动作两个收获。
3. **周日 20 分钟抽查**：随机抽 3 条旧题口述，答不上就退回 🟡。这条是防止「学过 = 会了」的错觉。
4. **12-01 起集中补**：项目收口后没有开发任务，那时再把 ⬜ 的按「JS → Vue3 → CSS → 手写」顺序清。优先级不能反。

## 判断标准（唯一一条）

不是「看过」，是**被追问三层还站得住**。

举个合格的例子：问「防抖是什么」→ 能说实现 → 能说项目里哪里用了（草稿 2 秒落盘）→ 能说 `immediate` 场景下和节流的区别。三层都答得上才算 ✅。
