### 11-24 基线实测结论（12:20）

- **长任务 0 个** → 基线状态下主线程没有任何一段超过 50ms，**不存在可优化的卡顿**；rAF 合并预计测不出差异。
- **240 fps 不作数**：rAF 计数器统计的是回调执行次数，空转也会打满刷新率，只能证明显示器是 240Hz，不能证明渲染流畅。
- **29.3s 是模型生成 + 网络的时间**，前端改动无法影响。
- 结论：README 原「长任务 50+ → 个位数 / 30fps → 60fps」确认是未测过的编造，须改写。
